# 🧗 ClimbU - Código Fuente del Proyecto

Proyecto desarrollado con React 19, Vite, Tailwind CSS y TypeScript.

## 🛠️ Instalación y Ejecución Local:

```bash
# 1. Instalar dependencias
npm install

# 2. Iniciar servidor de desarrollo local
npm run dev

# 3. Compilar para producción
npm run build
```
